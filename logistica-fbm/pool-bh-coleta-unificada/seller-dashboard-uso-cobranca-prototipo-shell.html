🏠 Início

Visão geral do ecossistema BH (todos os módulos). Fora do escopo deste protótipo — foco aqui é BIG logistics.

📦 Catálogo

BHID, variantes, medidas físicas. Spec em Requirements/catalogo.md.

🛒 Vitrine

Loja própria do seller. Spec em Requirements/vitrine-loja-propria.md.

👤 Cadastro

Dados fiscais, IVA por país, VIES. Spec em Requirements/cadastro-lojistas.md.

Endereços

Origens (warehouses) com janelas de coleta. Cadastrado no Setup wizard (Fase 1).

Embalagens

Caixas P/M/G + medidas. Cadastrado no Setup wizard (Fase 2).

Carriers & contratos

Pool BH + contratos próprios. Import POC de PDF disponível para 2–3 carriers.

Configurações & regras

Hub de regras (roteamento + embalagem). Should-have v1.5.

Módulos

Catálogo de módulos do ecossistema BH (ativar/desativar). BIG logistics está ativo.

Subscrições

Gerenciar assinaturas ativas. BIG logistics: €99/mês · ativa desde Fev/2026.

💬 Suporte

Chat com CSM, base de conhecimento, abrir ticket.

⚙ Configurações

Conta, segurança, notificações, idioma.

Clique nos itens da sidebar para alternar views · use as tabs de cenário em Uso & cobrança.
