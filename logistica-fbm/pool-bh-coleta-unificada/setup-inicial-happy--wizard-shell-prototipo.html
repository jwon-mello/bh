Tarifas — Pool BH ou contrato próprio?

Como você quer obter as tarifas das transportadoras? Você pode trocar depois.
🤝 Pool BH
recomendado
Tarifas agregadas que BH negocia com DPD + GLS para todos os sellers. Volume coletivo = preço melhor que conta individual.
✓ Sem negociação
✓ Pricing transparente
✓ Cobertura EU continental
