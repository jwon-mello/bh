Resumo: 4 regiões × 3 variações = 12 mini-sketches para validar.
Pontos críticos detectados: (1) R3 (regras) é o coração — variação A (tabela) é auditável; B (cards) é visual; C (agrupado) reflete categorias. (2) R4 (health-check) é redundante com wizard-resumo-ativacao — variação C (não ter) é defensável. (3) "+ criar regra" abre regra-builder em todas variações de R1.
Combinação validada ✓: 1B · 2B · 3B · 4 descartada
Decisão: R4 (health-check) descartada — info vive apenas em wizard-resumo-ativacao para evitar duplicação.
